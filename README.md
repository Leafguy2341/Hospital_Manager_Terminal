# Hospital_Manager_Terminal
This is the first ever project I did in OOP class during the journey of learning coding in University. This project is Hospital Managing, running in terminal with simple text data.

This is the structure of the files:
- Classes_2: contain all the objects java file, include Superclass/Supclass
- data: contain all the data files txt type
- interface: contains one file manage the interface type
- list: contain all the objects as a list in java
- manager: mainly contains GUI and BUS objects and a main file to run the project
